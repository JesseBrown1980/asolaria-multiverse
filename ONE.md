## The key

```text
cost(N, b) = b · ln(N)/ln(b)          d/db (b/ln b) = 0  at  b = e = 2.718281828
|e − 3| = 0.281718        |e − 2| = 0.718282        three is nearer

base 3  = 1.0000   the optimal integer radix
base 2  = 1.0566   binary, 5.66% more expensive, for every N, because N cancels
```

Checked exhaustively over integer bases 2..16 and `N = 10¹ … 10⁶⁰`: **base 3 minimises 60 of 60,
zero exceptions.** Every rung of the ladder is a whole number of trits and never a whole number of
bits — `3⁷` in 12 bits wastes **1,909 of 4,096** states.

**Integer and ternary is measured, not preferred.** That is the key, and a key opens rather than
spends.
